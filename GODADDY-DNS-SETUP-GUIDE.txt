PHASE 2: GODADDY DNS CONFIGURATION (Do Second)
───────────────────────────────────────────────

1. Go to: https://www.godaddy.com
2. Log in to your account
3. Click: "My Products" or "Domains"
4. Find your domain
5. Click: "Manage DNS"

For EACH domain, you'll see DNS records.
Firebase will provide you with specific records to add.

Typical Firebase A Records (you'll get exact ones from Firebase):
   • 199.36.158.100
   • 199.36.159.100
   • 199.36.160.100
   • 199.36.161.100


DOMAIN 1: www.prevleakgroup.co.za (QVEDIC)
────────────────────────────────────────────

1. In GoDaddy DNS Management, find "A Records" section
2. Look for existing "www" record
3. Update it OR create new one:

   Type: A (Address Record)
   Host/Name: www
   Points to: 199.36.158.100 (Firebase will show exact IP)
   TTL: 600 or 3600 (GoDaddy default is fine)
   Priority: N/A (not needed for A records)

4. Add remaining Firebase A records (usually 3-4 total)
5. Remove old records pointing elsewhere
6. Click Save

Expected: Within 1-5 minutes, https://www.prevleakgroup.co.za shows your Qvedic website

🆘 TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

PROBLEM: Firebase shows "Verification Pending" after 30 minutes
─────────────────────────────────────────────────────────────
Solution:
1. Go to GoDaddy > DNS Settings for your domain
2. Verify A records are set correctly
3. Check TTL (Time To Live) - set to 600 or lower
4. Wait another 15-30 minutes
5. Refresh Firebase console

PROBLEM: Domain shows error or blank page
────────────────────────────────────────
Solution:
1. Make sure you added ALL Firebase A records (usually 4)
2. Don't mix with other hosting service records
3. Remove old A records pointing to other services
4. Wait 5-10 minutes for DNS to propagate
5. Clear browser cache (Ctrl+Shift+Del)

PROBLEM: HTTPS certificate not provisioning
─────────────────────────────────────────
Solution:
1. Make sure domain is "Connected" in Firebase
2. Firebase needs 5-15 minutes to provision SSL
3. Check Firebase > Hosting > Domains > [Your Domain]
4. Status should change from "Provisioning" to "Connected"
5. Refresh page to see updated status

PROBLEM: www.yourdomain.co.za works but yourdomain.co.za doesn't
──────────────────────────────────────────────────────────────
Solution:
1. Add BOTH records in GoDaddy:
   • A record with Host: www
   • A record with Host: @ (root domain)
   Points to same Firebase IP
2. Save both
3. Wait 5-10 minutes
