## 3. Template direction adopted for the website

The website should remain simple, clear, and credible. The design direction is:
- clean business-style landing page
- one reusable layout across the main site and product pages
- logos and content placed as the primary brand elements
- color updates limited to the existing brand palette

### Approved visual palette
- Deep navy for trust and authority
- Blue for primary action and navigation
- Teal for supporting accents and calm confidence
- Amber for highlights and calls to action

## 5. Website build notes

Use this set of principles when building or refining the public-facing templates:
1. Keep the layout calm and easy to understand.
2. Show the real logos as the first visual anchor.
3. Keep copy concise and business-ready.
4. Use the same structure across the home, product, and support pages.
5. Let the brand colors guide the accents rather than introducing unrelated visual styles.
