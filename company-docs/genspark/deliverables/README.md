# GenSpark Deliverables Archive

This folder is the local archive for all GenSpark-generated design assets, website templates, app templates, source files, and reference documents.

## Suggested structure
- logos/
- website-templates/
- app-templates/
- brand-guidelines/
- source-files/
- exports/

## Use
- Store every GenSpark output here as the local working archive.
- Upload the same files to Google Drive in the matching folders once the assets are received.
- Keep this folder as the canonical local reference for the company brand system.
