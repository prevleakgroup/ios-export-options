# GenSpark Implementation Guide

## Brand direction
- Saferide should use a corrected orange-and-galaxy background visual system, with a cleaner, more professional logo treatment.
- Driver should use a black-and-orange palette with white CTA buttons and simple, clean calls to action.
- Rider should follow an orange-and-white logo system and a matching website palette.
- Palettemath should be treated as a multi-dimensional 2D semi-transparent cubic logo experience, with rotation and spin animation in the website and app iconography.
- Qvedic should remain premium, polished, and human-centered.

## Functional requirements
- All websites must have clear, simple CTA buttons.
- All websites and apps must include active Android and iOS download links.
- Each website must include sections for product overview, documentation, and app availability.
- App store assets should reflect the same brand system and remain professional.
- Marketing materials should be prepared for a 30-day ad campaign via GoDaddy.

## Visual system
- Saferide: orange + galaxy-inspired background, refined logo, app-store-ready icon, modern website presentation.
- Driver: black + orange + white, strong contrast, high clarity, clean simple CTAs.
- Rider: orange + white, calm confidence, app-friendly logo, consistent website treatment.
- Palettemath: semi-transparent cubic 2D logo, subtle spin/rotation, modern high-tech feel.

## Documentation and assets
- Use Google Drive files from the linked account as reference when available.
- Build documentation/profile pages for each website and app so each use case and function is clearly represented.
- Create marketing collateral and landing-page content suitable for GoDaddy ad scheduling.
