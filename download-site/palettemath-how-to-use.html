API and IP protection controls

  • Never expose API keys in frontend HTML, JavaScript, or docs.
  • Use server-side proxy endpoints for all protected model calls.
  • Apply token scoping, request signing, and per-tenant rate limits.
  • Disable verbose stack traces and internal model metadata in public responses.
  • Log abnormal scraping patterns and auto-block abusive clients.
