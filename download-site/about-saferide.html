Petrol surge support feature

Saferide includes a petrol surge support model that helps riders and drivers respond to fuel price volatility with transparent fare guidance, route efficiency recommendations, and clear service communication.

Formula: Surge adjustment = Base fare x [1 + ((Current petrol price - Baseline petrol price) / Baseline petrol price) x Sensitivity factor]

Variable guide: Base fare is the standard trip fare, baseline petrol price is the reference fuel price, current petrol price is the latest verified price, and sensitivity factor is an operator control value (typical range 0.25 to 0.60).

Example: Base fare = R100, baseline petrol = R20/L, current petrol = R24/L, sensitivity = 0.50. Surge adjustment = 100 x [1 + ((24 - 20) / 20) x 0.50] = R110.
