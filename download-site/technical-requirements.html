Palettemath API protection controls

  • Never publish API keys or secrets in HTML, JavaScript, or public docs.
  • Route protected calls through server-side endpoints only.
  • Use scoped tokens, rate limiting, and request origin checks.
  • Return minimal public responses and hide internal model metadata.
  • Monitor scraping and block suspicious automation patterns.

Saferide petrol surge formula standard

Formula: Surge adjustment = Base fare x [1 + ((Current petrol price - Baseline petrol price) / Baseline petrol price) x Sensitivity factor]

  • Base fare: standard fare before surge support.
  • Baseline petrol price: approved reference price per update cycle.
  • Current petrol price: latest validated fuel price in market.
  • Sensitivity factor: policy coefficient set by operations.

Set a minimum floor at 1.00x and a maximum cap according to policy to keep rider fairness and driver sustainability balanced.

Temperature-compensated methane estimation

Formula: Adjusted methane index = Raw methane sensor reading x [1 + Temperature coefficient x (Current temperature - Reference temperature)]

  • Raw methane sensor reading: calibrated baseline signal from the methane sensor.
  • Temperature coefficient: sensor-specific compensation factor derived from calibration.
  • Reference temperature: the calibration temperature used as the baseline.
  • Current temperature: the live ambient or enclosure temperature at the sensor.

This is a temperature-compensated estimate, not a direct measurement from temperature alone. Use it with the methane sensor, calibration data, and validation rules.
