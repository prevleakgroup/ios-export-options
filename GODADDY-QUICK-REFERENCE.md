## **SETUP FLOW FOR EACH**

1. ✅ **Create Website** → Use AI Website Builder
2. ✅ **Pick Template** → Match category above
3. ✅ **Use AI Assistant** → Tell it the brand story (see detailed guide)
4. ✅ **Upload Logo** → From `download-site/assets/`
5. ✅ **Publish** → Click Publish button
6. ✅ **Verify Live** → Visit domain in browser (takes 5-10 min)

## **AI Prompt Template**

Use this structure for each brand in GoDaddy AI:

```
"I'm launching [BRAND NAME] - [ONE-LINE DESCRIPTION].
Create sections for:
- Hero headline: [HEADLINE]
- 4-5 key features: [FEATURES]
- Call-to-action buttons: [BUTTONS]
- Social proof or testimonials
- Contact / support section"
```
