🚀 HOW TO RUN
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Start All Servers:
   1. Open PowerShell in project directory
   2. Run: node publish-all-public.js
   3. All 5 servers start on ports 8081-8085
   4. Sites accessible at URLs above

Stop Servers:
   - Press Ctrl+C in terminal
   - Or run: .\port-forwarding-setup.ps1 -StopAll

Check Status:
   - Run: .\port-forwarding-setup.ps1 -CheckPorts
   - Run: netstat -an | find "8081"

📞 SUPPORT & TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Common Issues:

"Port already in use"
   → Solution: Stop other servers on that port
   → Run: .\port-forwarding-setup.ps1 -StopAll

"Can't connect from outside network"
   → Solution: Wait 5-15 minutes for DNS to propagate
   → Verify: https://www.whatismyipaddress.com/dns-lookup

"Firewall blocking connection"
   → Solution: Run firewall script as Administrator
   → Run: .\enable-public-firewall.ps1

"Port shows closed on canyouseeme.org"
   → Solution: Restart router, wait 2 minutes
   → Verify router port forwarding is enabled
   → Check ISP isn't blocking port
